# 朔望月

《朔望月》是一款可离线运行的中文网页卡牌游戏试玩版。游戏以中国节气、传统农历节日和月相变化为主题，融合牌力判断、轮流下注、资源管理与角色技能。

项目不依赖构建工具、包管理器或外部网络资源，支持直接打开 `index.html`。为避免浏览器对本地资源的限制，推荐使用静态服务器运行。

## 启动游戏

在项目目录执行：

```powershell
python -m http.server 4317 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4317/
```

## 当前内容

- 36 张主题牌：24 张节气牌与 12 张传统农历节日牌。
- 最多八回合牌局，支持不同人数和人机难度。
- 每名角色初始拥有 20 道，每回合仍在场的角色强制投入 1 道。
- 前四回合为朔月，总牌力越高越强。
- 后四回合为满月，动态月限依次为 44、48、52、56，最接近且不超过月限者获胜。
- 逐席行动、跟注、加注、弃权、尽数投入、道尽待判与满月赌命。
- 普通易牌全局共两次，仅可在前四回合使用；“逐月”可以额外奖励易牌机会。
- 两套界面主题“原有月庭”和“宫灯漆金”，以及沉浸、标准、快速三档节奏。
- 新手教学、牌力侧栏、终局排名、回合复盘、本地战绩与观月札记。
- 手机网页使用横屏牌桌；竖屏时会提示旋转设备，Android WebView 也固定为横屏。
- 加注滑轨只用于预选金额，必须点击“加注”确认后才会投入道；非本人回合也可以提前预选。

## 新手教学

教学按朔月基础、技能教学、满月规则三个阶段解锁，并采用“上一步 / 下一步”浏览。未解锁的下一步会明确提示当前仍不可查看；完整走过一次教学后，所有阶段都可以自由前后浏览。教学进度保存在 `shuoWangTutorialProgressV3`。

1. 朔月阶段：认识牌面、牌力、道、跟注、加注、弃权和回合结束。
2. 技能阶段：只讲当前技能的目标、决策者、可见范围和结果；阶段末可点击展开通用的全角色技能简介。
3. 满月阶段：说明月限、超限判负、暗牌比较、赌命和最终结算。

## 角色技能

六名角色均拥有一个主动技能和一个无负面效果的被动技能。主动技能通常每回合可发动一次；丹枝的“同契”每局限用一次。

| 角色 | 主动技能 | 被动技能 |
| --- | --- | --- |
| 霜弦 | **封月**：锁住任意角色的一张明牌或暗牌，使该牌本回合按 0 点计算。 | **霜境**：所有对白狐·霜弦使用主动角色技能的角色获得“霜痕”；其下一回合主动技能被封，正常下注不受影响。 |
| 墨岳 | **撼岳**：指定一名对手；“迎锋 / 敛势”只能由被攻击者选择。 | **镇岳**：每次跟注永久减免 1 道，仍视为完整跟注。 |
| 丹枝 | **同契**：与一名敌人秘密选择“同月”或“背月”；选择相同则丹枝获胜，否则对方获胜。胜者可令败者本回合弃权，或取走其 2 道。 | **回枝**：输掉本回合但仍存活时恢复 3 道，全局最多触发 3 次。 |
| 星烬 | **鹰瞰**：每回合查看一名对手的暗牌，情报保留到回合结束，可通过“情报”按钮再次查看。 | **追影**：连续两回合鹰瞰同一角色后，持续获知该角色当前及以后回合的技能使用方向。 |
| 夜岚 | **断势**：加注时限制一名目标的下一次行动只能跟注或弃权。 | **逐寂**：每当有人淘汰便获得 3 道；若对方淘汰的回合受到夜岚的断势，再额外获得 2 道。 |
| 月栖 | **借月**：每回合秘密选择 -5 至 +5，修正本回合牌力。 | **逐月**：明牌和暗牌同时高于或低于公共牌时获得一次易牌；易牌后仍满足条件可再获得一次，每回合最多两次。 |

## 交互反馈

### 技能权限摘要

- 撼岳：发起者指定目标；迎锋 / 敛势只能由被攻击者点击。
- 同契：发起者和被攻击者都必须各自选择同月 / 背月；双方不能代选。规则判定胜负后，发起者决定弃权 / 取走 2 道，负面效果自动执行给败者。
- 霜境：所有对白狐·霜弦使用主动技能的角色获得霜痕，下一回合主动技能封锁；普通下注不受影响。
- 私密性：玩家只能看到与自己相关的选择；AI 对 AI 的选择方向和按钮全部隐藏。

- 角色技能、下注动作和回合结算使用统一操作锁串行执行，上一段演出或操作结束后才会进入下一项。
- “技能影院 + 选择界面”先播放完整演出，间隔 0.5 秒后再显示选择，避免界面重叠。
- 回合结束按“拼点揭示、结算被动、淘汰奖励、回合结果”的顺序执行。
- 所有技能均提供结果回执，明确发动者、目标、选择、牌或道的变化，以及效果的持续时间。
- 封月会在牌面显示强化后的月锁封印与 0 点状态；牌的交换、送出和替换均有明确的起点、移动过程与落点。
- 撼岳和同契的决策界面只展示给有权决策的角色；AI 对 AI 的技能选择对玩家隐藏。规则层还会验证 `phase` 和 `decisionMakerId`。
- 霜境失败反馈明确显示“霜境保护”，不会误报为封月锁定。

## 项目结构

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` | 页面结构、游戏 HUD、对话框和操作入口 |
| `game.js` | DOM 渲染、交互与牌局流程编排 |
| `game-data.js` | 角色、技能和牌库数据 |
| `game-rules.js` | 牌力、合法操作、胜负与技能规则 |
| `game-ai.js` | 遵守隐藏信息边界的人机决策 |
| `game-runtime.js` | 可取消的流程计时器与三档游戏节奏 |
| `styles.css`、`table-theme.css`、`ui-polish.css` | 基础布局、牌桌主题与最终视觉覆盖 |
| `imperial-theme.css` | “宫灯漆金”可选主题 |
| `motion-effects.*` | 全局动态背景与微交互 |
| `skill-effects.css` | 六名角色的技能演出 |
| `assets/` | 六名角色的本地 SVG 头像 |
| `audio-options/` | 三段本地背景音乐 |
| `tests/` | 核心规则、人机公平性与计时器测试 |

## 本地验证

检查主脚本语法：

```powershell
node --check game.js
```

运行全部自动测试：

```powershell
node --test tests\*.test.js
```

## 数据与限制

战绩、札记、教学状态、主题和速度设置均保存在浏览器 `localStorage` 中。当前版本为单机试玩版，不包含真人联网匹配、后端账号或云端存档。

安卓工程位于 `android-app/`，使用原生 WebView 离线封装游戏。调试安装包构建完成后输出到 `output/apk/shuo-wang-yue-demo.apk`，可直接传到安卓手机安装试玩。手机需要允许当前文件管理器或传输工具“安装未知应用”。
